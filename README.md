# HECTORFLEX Official Discord Bot 🤖

Official bot project for the HECTORFLEX digital mart. This new bot is separate from the older Hector Flex Helper.

## Planned modules
- Slash commands and store status
- Vouch and order-proof channel integration
- Explicitly approved public proof feed for the portfolio
- Tickets, order handling and moderation (future phases)
